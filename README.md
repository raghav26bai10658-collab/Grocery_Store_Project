# Grocery Store Management System

## Overview
A Python-based application designed to help neighborhood grocery stores manage their inventory and process customer sales efficiently.

## Features
* Inventory Management (Add, View, Update stock)
* Point of Sale (POS) Billing and Receipt Generation
* Low Stock Analytics & Reporting

## Technologies Used
* Python 3.x
* CSV standard library (for database storage)

## Steps to Install & Run
1. Ensure Python 3 is installed on your system.
2. Download all repository files into a single folder.
3. Open a terminal or command prompt in that folder.
4. Run the command: `python main.py`

## Instructions for Testing
* Launch the application and select option 2 to add test products.
* Select option 1 to verify products were added.
* Select option 3 to simulate a sale and generate a receipt.
* Select option 4 to test the low-stock warning threshold.
